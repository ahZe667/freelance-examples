# Playlist Recommender — personalised music recommendations

**Personal project · Flask · data preparation · clustering · ranking**

## Problem and workflow

User ratings provide input for generating music recommendations. The documented
application prepares features, handles duplicates, clusters data and uses positive
and negative feedback in a diversity-aware ranking.

[Public source code](https://github.com/ahZe667/playlist_recommender).

## Relevant client application

Prototype a recommendation workflow, define its inputs and outputs, and expose it
through a focused web interface. Evaluation criteria and suitable data are agreed
for each client project.
